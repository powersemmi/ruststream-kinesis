# Путь

Путь записи Kinesis через сервис RustStream: чтение, доставка, обработчик, ответ и контрольная
точка, по одной записи или пакетами.

<Diagram name="path" words={words} />

Читатель сегмента запрашивает до 1000 записей за один `GetRecords`. Каждая запись становится
сообщением [`KinesisMessage`](api:ruststream_kinesis::KinesisMessage), которое хранит данные записи
в том виде, в каком их декодировал SDK. [Конверт](kinesis/index.md) подписки находит в них полезную
нагрузку. Заголовки читаются, когда их впервые запрашивают: заголовки конверта, а также ключ
сегмента, порядковый номер и идентификатор сегмента. Доставка также занимает своё место
в отметке подтверждения сегмента, которая определяет её контрольную точку. Это несколько выделений
памяти на запись, а сколько стоит запись, публикует страница [Бенчмарки](/architecture/benchmarks/).

Все читатели подписки отправляют доставки в один канал на 64 места. Пока канал полон, читатель
ждёт, поэтому темп чтения задают обработчики. Перед отправкой чтение получает метку: если подписка
[перематывается](kinesis/reading.md), пока чтение ещё выполняется, его записи отбрасываются на
выходе из канала и никогда не попадают в обработчик.

Подписка на пакеты делает размер пакета лимитом каждого чтения, но не больше 10 000 записей,
которые может вернуть одно чтение. Пакет закрывается, когда в нём набирается столько записей,
или через 50 миллисекунд после его первой записи, поэтому пакет часто меньше заданного размера.
Пакет может содержать записи нескольких сегментов. Каждый элемент завершается сам, со своей
контрольной точкой.

Ответ кодируется в буфер, который цикл диспетчеризации использует повторно. Ключ сегмента берётся
из вызова публикации, затем из заголовка `partition-key`, затем из политики. Запись, которой никто
не задал ключ, получает ключ, распределяющий записи по сегментам. Заголовки попадают в конверт
издателя. В конверте по умолчанию ответ без заголовков - это закодированный буфер без изменений,
если только он сам не начинается как конверт.
[`KinesisPublisher`](api:ruststream_kinesis::KinesisPublisher) пишет его одним вызовом
`PutRecord` через клиент SDK того рантайма, который публикует.

Доставка завершается после ответа. `ack` записывает контрольную точку, только когда сдвигает
отметку подтверждения сегмента, как показывает страница [Завершение](settlement.md).
