# Партиции воркеров

Одна подписка читает каждый свой сегмент отдельным читателем через один канал, а
`workers(n, by_key)` раскладывает записи по партициям воркеров, выбирая их по ключу сегмента.

<Diagram name="lanes" words={words} />

Поток доставок подписки выдаёт по одной записи, из какого бы сегмента она ни пришла. Без `workers`
один цикл вызывает обработчик для каждой записи по очереди, поэтому каждый сегмент сохраняет
порядок, и ничего не выполняется параллельно. `workers(n)` выполняет до `n` обработчиков
одновременно, без определённого порядка.

`workers(n, by_key)` запускает `n` партиций воркеров, и запись попадает в ту партицию воркеров, на
которую указывает хеш её ключа. Ключ - это заголовок
[`PARTITION_KEY_HEADER`](api:ruststream_kinesis::PARTITION_KEY_HEADER), который каждая доставка
заполняет собственным ключом сегмента записи. Поэтому записи одного ключа никогда не расходятся по
двум партициям воркеров, и порядок, который Kinesis соблюдает для ключа в его сегменте,
сохраняется в сервисе. Если партиций воркеров меньше, чем ключей, каждая обслуживает несколько
ключей.

Все читатели подписки отправляют доставки в один канал на 64 места. Когда обработчики отстают,
канал заполняется, все читатели ждут, и ни один сегмент не читается дальше, чем сервис успевает
обработать. Подтверждения из параллельных партиций воркеров приходят не по порядку, а контрольная
точка всё равно никогда не обгоняет незавершённую запись, как показывает страница
[Завершение](settlement.md).

Экземпляры сервиса с общей [таблицей аренд](kinesis/leases.md) делят сегменты: каждый сегмент в
один момент читает один экземпляр, а новый экземпляр берёт сегменты по мере того, как их аренды
освобождаются. Со стандартным [`MemoryLeaseStore`](api:ruststream_kinesis::MemoryLeaseStore)
каждый экземпляр хранит собственные аренды, поэтому каждый читает все сегменты.

[Обработчик пакетов](path.md) берёт записи до размера, заданного в точке монтирования, или то,
что пришло за 50 миллисекунд после первой записи пакета, поэтому пакет часто меньше этого размера.
