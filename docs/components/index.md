# Components

The parts of `ruststream-kinesis` a Kinesis service uses, one page per component: the broker
([`KinesisBroker`](api:ruststream_kinesis::KinesisBroker)), its stream subscriptions, its publish
policy, the lease stores and the in-process transport a
[`TestApp`](api:ruststream::testing::TestApp) test runs on.
